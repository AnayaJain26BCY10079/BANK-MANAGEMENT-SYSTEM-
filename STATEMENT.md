Bank Management System
The Bank Management System is a Python-based GUI application designed to provide basic banking operations in a simple and user-friendly interface. The project demonstrates the use of Python, Tkinter, Matplotlib, functions, conditional statements, data structures, and input validation.

The system provides separate interfaces for users and administrators. Users can view and update their account information, perform deposit and withdrawal transactions, check loan status, view their passbook, and submit feedback. Administrators can manage accounts, update loan information, view loan defaulters, review feedback, and perform banking transactions.

The project stores account and loan information using Python dictionaries and lists instead of an external database. It also includes a loan graph created using Matplotlib to provide a visual representation of loan data.

Objective
The main objective of this project is to develop a simple banking application that demonstrates how Python programming concepts can be combined to create a functional Bank Management System with a graphical user interface.

Technologies Used
Python
Tkinter – Graphical User Interface
Matplotlib – Graphs and data visualization
Datetime – Date and time handling
Random – Random number generation
Project Scope
This project is developed for educational purposes to demonstrate basic banking operations and Python programming concepts. It is not intended to be used as a real-world banking application.
